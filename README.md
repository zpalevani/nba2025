# NBA 2025

A notebook-based NBA data analysis project.

## Project notebook

[Open NBA.ipynb](NBA.ipynb)

## Getting started

1. Open the notebook on GitHub to inspect the analysis.
2. Download it and open it in a Jupyter-compatible environment such as Google Colab.
3. Follow the notebook's installation and data-loading cells before running the analysis. Adjust any local file paths for your environment.

The repository contains the notebook; separate input datasets and environment lockfiles are not included. Results may depend on the available data and library versions.
